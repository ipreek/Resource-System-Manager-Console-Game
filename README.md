## Resource-System-Manager-Console-Game
    Simple game about managing resources and buying factories, that helps you to do the work.

    Use console command to control in-game actions. Press key on keyboard => press enter.
    - Work for money.
    - Buy buildings to produce resources.
    - Sell resources to make more money.
    - Be careful! If you not manage your plan carefully you can fall into bankruptcy.
    - You can sell unprofitable buildings to emerge from bankruptcy.

    If you added something in game via config.json or [yourLang].json and want to undo your changes just delete that files and run game another time.
